# Design notes — Concept A / Editorial Data Atlas

## Visual direction
A light editorial research identity combined with an interactive, district-led data observatory. The overall canvas stays warm-white and pale green. Deep forest green is reserved for primary actions, the logo mark and text emphasis—not for large dark page backgrounds.

## Palette
- Paper: `#F4F6EF`
- Surface: `#FBFCF8`
- Pale sage: `#E2EBDF`
- Forest ink: `#1E382D`
- Muted sage: `#6F9079`
- Clay accent: `#D58A69`
- Soft gold: `#D7BD7E`
- Hairline: `#DCE4D9`

## Typography
- Display/editorial: Newsreader
- Body/navigation: DM Sans
- Metadata/data labels: IBM Plex Mono

## Visual signatures
- A CSS 3D orbital research object in the home hero (no image API or remote visual asset required).
- Custom contour illustrations for climate research.
- A schematic Maharashtra district locator with selectable sample points.
- Editorial ruled lists, numbered research indexes and deliberately asymmetrical layouts instead of generic card grids.
- Motion is restrained and includes reduced-motion support.

## Functional prototypes
- Two switchable synthetic datasets: climate heat-readiness and renewable-energy capacity.
- Map, chart and table modes.
- District selection, table search, CSV downloads and README downloads.
- Dataset caveat shown in the interface and in each README.

## Before a public launch
Replace all synthetic numbers with verified source data, replace the schematic map with licensed/verified district GeoJSON, connect the real dataset pipeline, confirm the final logo and review research content with the team. Do not publish prototype values as findings.
